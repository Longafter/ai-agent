# ✅ 代码提交前审查清单 (Pre-Commit Checklist)

> Agent 在提交代码前必须逐条对照本清单进行自检。

## 功能完整性
- [ ] 新增的函数/方法是否有对应的使用场景？是否被正确调用？
- [ ] 修改的逻辑是否完整覆盖了需求描述中的所有场景？
- [ ] 边界条件（空值、空数组、超长字符串等）是否已处理？

## 代码规范
- [ ] 变量和函数命名是否语义清晰（禁止 `a`, `b`, `temp`, `data` 等模糊命名）？
- [ ] 复杂函数是否已添加 JSDoc 注释（含参数类型和返回值）？
- [ ] 是否存在重复代码？能否抽取公共函数？

## 安全性
- [ ] 是否存在硬编码的密码、Token 或 API Key？
- [ ] 用户输入是否经过校验或转义（防止注入攻击）？

## 性能
- [ ] 是否存在不必要的循环嵌套（O(n²) 或更差的复杂度）？
- [ ] 大数据量操作是否考虑了分页或流式处理？

## 兼容性
- [ ] 修改是否影响了其他模块的正常运行？
- [ ] 是否需要同步更新配置文件、文档或依赖版本？
